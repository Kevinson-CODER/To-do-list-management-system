PROBLEM STATEMENT :-
In To do list management system, user requires to enter their choices and operator the modules to get the desired result.It contains all the required fields in a task management like adding , viewing, updating, completion status and etc. It tracks every tasks 
SCOPE OF THE PROJECT :-
 It allows the user to input the tasks, add a task, view a task, update , edit,delete a task and it have the CLEAR choice option to clear the screen.It can run locally on any system.
Target Users :-
 Students , workers who are in need to check their tasks regularly . first sem student to build their first project.
High Level features :- 
contains the datetime, time, calender modules.
